# Trabajo Práctico 2 - JavaScript

Este repositorio contiene la resolución de ejercicios de JavaScript.

## Temas trabajados

- Condicionales
- Bucles
- Math
- String

## Estructura del proyecto

- `index.html`: archivo principal para probar los ejercicios
- `js/`: carpeta con los ejercicios resueltos individualmente

## Ejercicios resueltos

- Ejercicio 1: validación de edad para conducir

- Ejercicio 4: suma de números hasta cancelar
- Ejercicio 5: cálculo de letra de DNI
- Ejercicio 6: pirámide del 1 al 30
- Ejercicio 7: pirámide inversa
- Ejercicio 8: pirámide creciente
- Ejercicio 9: múltiplos de 4 y 9
- Ejercicio 10: tabla descendente
- Ejercicio 11: nombre de la persona mayor
- Ejercicio 12: número aleatorio entre 1 y 99
- Ejercicio 13: texto en mayúsculas
- Ejercicio 14: texto con guiones entre caracteres
- Ejercicio 15: conteo de vocales
- Ejercicio 16: texto invertido
- Ejercicio 17: posición de la primera vocal
